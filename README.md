## 🌟 Features

- 🔍 **Real-time Tumor Detection**: Advanced YOLO v8 model for accurate brain tumor detection
- 📊 **Confidence Scoring**: Detailed confidence scores for each detection
- 💫 **Beautiful UI**: Modern, responsive interface with Next.js 13
- 🖼️ **Image Preview**: Full-screen image preview with detection overlays
- 📱 **Mobile Friendly**: Responsive design that works on all devices
- 🚀 **Fast Processing**: Optimized for quick analysis and results

## 🛠️ Tech Stack

### Frontend
- 🎨 Next.js 13 with App Router
- 💅 Tailwind CSS for styling
- 🎭 Framer Motion for animations
- 📱 Responsive design principles

### Backend
- 🐍 Python with YOLO v8
- 🤖 Advanced ML model for tumor detection
- 🌐 RESTful API endpoints
- 📝 Detailed logging and error handling

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/medai-assist.git
   cd medai-assist
   ```

2. **Install dependencies**
   ```bash
   # Frontend
   cd medai-assistant
   npm install

   # Backend
   cd Back-end
   pip install -r requirements.txt
   ```

3. **Verify setup**
   ```bash
   # Test the YOLO model setup
   cd Back-end
   python test_single.py
   # This will run a test detection on a sample image
   ```

4. **Run the development server**
   ```bash
   # Frontend
   cd ../medai-assistant
   npm run dev
   ```

5. **Access the application**
   - Open http://localhost:3000 in your browser
   - Upload a brain MRI scan
   - Click "Analyze Images" to see results
